# SBB — портал шефа

Статический сайт для смен, зарплаты и чеклистов кухни (RU / EN / VI).

## Расчёт зарплаты (`acc/`)

Данные смен берутся из Google Sheets (CSV). В ячейках графика:

| Значение | Смысл |
|----------|--------|
| `1` или `3` | целая смена |
| `0.5` или `0,5` | полсмены (ставка × 0.5) |
| `0` | выходной |
| `VR` | выходной / VR |
| `Б` | больничный |

К выплате: `число смен × ставка + корректировка`.

При открытии страницы ЗП:
- показывается **сегодняшняя дата**;
- в селекторах автоматически выбирается **предшествующий** расчётный период:
  - если сегодня 1–15 → период **16–31 предыдущего месяца**;
  - если сегодня 16–31 → период **1–15 текущего месяца**.

В Google Sheet даты часто без года (два сезона подряд). Раньше `01.11` 2025 и `01.11` 2026 суммировались вместе.

Сейчас год берётся так:
1. если сверху есть строка **`Год`** — из неё (объединённые ячейки ок: в CSV год только в первой колонке блока, скрипт протягивает его дальше);
2. иначе год восстанавливается по порядку колонок (когда дата «прыгает» назад — следующий год).

Полсмены в ячейках: `0.5` или `0,5` (оранжевая подсветка, в ЗП = полставки).

## Локальный запуск

```bash
python3 -m http.server 3847 --bind 127.0.0.1
```

Открой `http://127.0.0.1:3847/` (код доступа на главной: `12321`, на странице ЗП: `32123`).
